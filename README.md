# OutToC Treasure Hunt

A tiny C++ console game where you, a brave adventurer armed with nothing but **WASD keys** and quesionable decision-making skills, wander around a grid looking for treasure.

It's simple.
It's silly
It's C.
And yes, it contains treasure, so technically this is a financially lucrative project.

---

## What is this?

OutToC Treasure Hunt is a minimalist game where:

- You are **P** (Player)
- Treasure is **T**
- Everything else is **dots**
- The dots do nothing
- The treasure does everything
- you get points
- You feel good
- That's game design

---

## How to Play

- Run the game
- Stare at the grid
- Press **W**, **A**, **S**, or **D**
- Move toward the treasure
- Miss the treasure
- Try again
- Eventually succeed
- Feel proud

---

## How to Run It

If you somehow lost the ability to type commands, here's a reminder:

```bash
g++ OutToC_Treasure.cpp -o OutToC_Treasure
./OutToC_Treasure
```

If it doesn't run, don't panic, just blame your compiler.
Developers have been doing this since the dawn of time.
